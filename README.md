# 📘 OpenBNCC – Simplificando a BNCC

O **OpenBNCC** é uma aplicação open source que ajuda professores a buscar, entender e utilizar habilidades da BNCC de forma rápida e prática.

A ferramenta permite pesquisar por código (ex: `EF06LP07`) ou por tema (ex: *hiperônimos*, *gêneros textuais*), retornando informações estruturadas e auxiliando no planejamento pedagógico.

---

## 🚀 Funcionalidades

- 🔎 Busca por código ou tema (semântica offline)
- 📚 Exibição estruturada das habilidades da BNCC
- 🧠 Geração automática de:
  - Metodologia de ensino  
  - Critérios de avaliação  
- 🤖 Automação de preenchimento em sistemas educacionais
- ⚡ Funciona 100% offline

---

## 🧩 Tecnologias

- Python  
- SQLite  
- Sentence Transformers  
- PyInstaller
